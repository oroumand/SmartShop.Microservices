# ADR-0002: استفاده از ASP.NET Core 10

## وضعیت

Accepted

## زمینه

برای پیاده‌سازی SmartShop به یک پلتفرم backend نیاز داریم که برای ساخت API، تست، Docker، EF Core و معماری ماژولار مناسب باشد.

مدرس کارگاه از اکوسیستم .NET استفاده می‌کند و مخاطبان کارگاه برنامه‌نویسانی هستند که قرار است معماری را در قالب یک پروژه واقعی تجربه کنند.

نیازهای اصلی تکنولوژی backend عبارت‌اند از:

- پشتیبانی مناسب از Web API
- پشتیبانی مناسب از dependency injection
- قابلیت ساخت Solution چندپروژه‌ای
- سازگاری خوب با EF Core
- سازگاری خوب با Docker
- قابلیت تست‌پذیری بالا
- مناسب بودن برای Minimal APIs یا endpoint-based modules
- مناسب بودن برای پروژه آموزشی و قابل ارائه در GitHub

## تصمیم

برای توسعه SmartShop از ASP.NET Core 10 استفاده می‌کنیم.

اپلیکیشن اصلی در پروژه `SmartShop.Api` قرار می‌گیرد و نقش Composition Root را دارد.

هر ماژول endpoints خودش را در پروژه جداگانه نگهداری می‌کند و در Host اصلی register می‌شود.

## پیامدها

### پیامدهای مثبت

- اکوسیستم .NET برای ساخت API و سیستم‌های سازمانی مناسب است.
- dependency injection به صورت built-in وجود دارد.
- ساختار Solution چندپروژه‌ای به خوبی پشتیبانی می‌شود.
- EF Core برای SQL Server پشتیبانی مناسب دارد.
- Dockerize کردن اپلیکیشن ساده است.
- نوشتن تست‌های معماری و integration tests امکان‌پذیر است.
- Minimal APIs برای endpointهای کارگاهی ساده و قابل فهم هستند.
- تکنولوژی برای مخاطبان .NET قابل دنبال کردن است.

### پیامدهای منفی

- شرکت‌کننده‌هایی که با .NET آشنا نیستند ممکن است نیاز به توضیح اولیه داشته باشند.
- نسخه 10 نسبتاً جدید است و ممکن است بعضی ابزارها یا extensionها هنوز کاملاً با آن هماهنگ نشده باشند.
- برای اجرای پروژه، شرکت‌کننده‌ها باید SDK مناسب را نصب داشته باشند.

## گزینه‌های بررسی‌شده

### ASP.NET Core 8

مزیت‌ها:

- پایدار و رایج
- ابزارهای بالغ
- جامعه کاربری بزرگ

دلیل انتخاب نشدن:

- هدف کارگاه استفاده از نسخه جدیدتر و آماده‌سازی برای آینده است.
- مدرس قصد دارد کارگاه را با ASP.NET Core 10 برگزار کند.

### Node.js و NestJS

مزیت‌ها:

- مناسب برای ساخت API
- ساختار ماژولار خوب
- جامعه کاربری گسترده

دلیل انتخاب نشدن:

- تمرکز کارگاه روی اکوسیستم .NET است.
- EF Core و SQL Server در .NET تجربه طبیعی‌تری برای این کارگاه فراهم می‌کنند.

### Java و Spring Boot

مزیت‌ها:

- مناسب برای معماری‌های سازمانی
- اکوسیستم بالغ

دلیل انتخاب نشدن:

- با استک مورد نظر مدرس هم‌خوان نیست.
- زمان کارگاه محدود است و نباید استک اصلی تغییر کند.
