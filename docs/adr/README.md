# تصمیمات معماری

این فولدر محل نگهداری ADRها یا Architecture Decision Recordهای پروژه SmartShop است.

هر ADR یک تصمیم مهم معماری را ثبت می‌کند و توضیح می‌دهد چرا آن تصمیم گرفته شده، چه گزینه‌هایی بررسی شده‌اند و پیامدهای مثبت و منفی تصمیم چیست.

## قالب ADR

هر تصمیم معماری با این ساختار نوشته می‌شود:

```text
# ADR-XXXX: عنوان تصمیم

## وضعیت

Accepted

## زمینه

شرح مسئله، محدودیت‌ها و نیازهای تصمیم‌گیری.

## تصمیم

تصمیم نهایی.

## پیامدها

پیامدهای مثبت و منفی تصمیم.

## گزینه‌های بررسی‌شده

گزینه‌های جایگزین و دلیل رد شدن آن‌ها.

## تصمیمات مرتبط

لینک یا اشاره به ADRهای مرتبط.
```

## وضعیت‌های مجاز

- Proposed
- Accepted
- Superseded
- Deprecated
